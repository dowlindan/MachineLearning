## Description 
This houses two scripts that predict a Cartiotocography dataset target (NSP) and classes for the yale faces dataset using Naive Bayes

## How to run
1. (Optional) Set and activate venv

 `python3 -m venv venv`

 `source ./venv/bin/activate`

2. Install requirements 

`pip3 install -r requirements.txt`

3. Run scripts

`python3 ./HW6_CTG.py`
`python3 ./HW6_YaleFaces.py`
